Entry for the [make.fun Best Turkey Escape Game Bounty](https://make.fun/bounty/turkey-run-game-01).

**Gobble Run** is an offline, pure Canvas 2D side-scrolling escape runner with procedural art and WebAudio-synthesised sound. Play as a turkey fleeing the farmyard at autumn dusk toward the Forest Gate while the farmer chases behind with a pitchfork.

## Controls

- **Jump:** `Space` / `W` / `Up Arrow` / Click or Tap
- **Duck:** `S` / `Down Arrow` / Swipe Down
- **Pause:** `P` / `Esc`
- **Restart:** `R`
- **Mute:** `M`

## Local Play & Handover

```bash
# Play locally
node serve.ts
# Open http://localhost:8080

# Build handover bundle
MAKEFUN_OUTPUT_DIR=out node main.ts
```
